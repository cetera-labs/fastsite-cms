# Интерфейсы back-office

В Fastsite CMS 3.x два интерфейса администрирования:

| Интерфейс | Где лежит | Статус |
|---|---|---|
| Старый back-office на ExtJS 4 | `cms/app/`, `cms/app.js`, `ext/` плагинов | Основной. Принимаются только исправления ошибок |
| Новый back-office на Ext JS 7 | `back-office/` | **Заморожен.** Не развивается |

## Новый back-office на Ext JS 7 заморожен

По плану развития в Fastsite CMS 4.0 оба интерфейса заменит новая админка на Vue 3, поэтому новый back-office на Ext JS 7 больше не развивается:

- новые функции, экраны и поля в `back-office/app` не добавляются;
- плагины не получают отдельный интерфейс под Ext JS 7. Признак `ext6_compat` у модулей новых плагинов не ставится;
- зависимости `back-office/` (webpack, Sencha Cmd и пр.) обновляются только для устранения уязвимостей, если это не ломает сборку;
- `back-office/build/` пересобирается только при исправлении ошибок в `back-office/app`.

## Что делать в старом back-office

Старый back-office на ExtJS 4 остаётся рабочим интерфейсом сайтов до перехода на 4.0. В нём исправляются ошибки,
а интерфейсы плагинов, как и раньше, пишутся классами ExtJS 4 в каталоге `ext/` плагина
(см. [Разработка плагинов]({{site.baseurl}}/docs/developer-guide/plugins/develop.html)).

Крупные новые функции интерфейса лучше не начинать на ExtJS 4: их придётся переписывать под Vue 3.
